# hope✳ — Your AI grant team

Hope finds grants that fit a nonprofit, explains what each one asks for, tracks deadlines, and drafts the
application for a human to review and approve.

This Space runs the same web app as the live site in **offline demo mode**: sample grants, and everything you
enter stays in your browser. AI drafting is turned off here, so the built-in template drafts instead.
